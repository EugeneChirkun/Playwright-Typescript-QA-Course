# Ресурсы: Модуль 12

## Playwright

- [Continuous Integration](https://playwright.dev/docs/ci) — официальное руководство по запуску Playwright в CI.
- [GitHub Actions](https://playwright.dev/docs/ci#github-actions) — официальный пример workflow для GitHub Actions.
- [HTML reporter](https://playwright.dev/docs/test-reporters#html-reporter) — настройка и открытие HTML report Playwright.
- [Trace Viewer](https://playwright.dev/docs/trace-viewer) — использование trace для анализа падений тестов.

## GitHub Actions

- [Документация GitHub Actions](https://docs.github.com/en/actions) — основные понятия, создание workflow и просмотр результатов запусков.
- [Синтаксис workflow](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions) — официальный справочник по структуре YAML-файла.
- [Хранение данных workflow как artifacts](https://docs.github.com/en/actions/using-workflows/storing-workflow-data-as-artifacts) — сохранение и загрузка отчетов между запусками.
- [Использование secrets в GitHub Actions](https://docs.github.com/en/actions/security-guides/using-secrets-in-github-actions) — базовое безопасное хранение чувствительных значений без добавления их в Git.
