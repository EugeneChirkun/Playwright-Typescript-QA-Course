# Ресурсы: Модуль 04

## Официальная документация

* [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) — основной справочник по TypeScript.
* [TypeScript Everyday Types](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html) — базовые типы, массивы, объекты и функции.
* [TypeScript Object Types](https://www.typescriptlang.org/docs/handbook/2/objects.html) — описание объектов, interfaces и optional properties.
* [TypeScript Narrowing](https://www.typescriptlang.org/docs/handbook/2/narrowing.html) — полезная тема для понимания условий и проверок типов.
* [TypeScript Modules](https://www.typescriptlang.org/docs/handbook/2/modules.html) — `export`, `import` и разделение кода на файлы.

## Инструменты

* [TypeScript Playground](https://www.typescriptlang.org/play) — онлайн-песочница для быстрых экспериментов с TypeScript.

## Дополнительная практика

* [Codewars](https://www.codewars.com/) — необязательная дополнительная практика.

Для Codewars выбирайте простые задания на JavaScript или TypeScript:

* начинайте с уровня `8 kyu`;
* фокусируйтесь на функциях, массивах, объектах и условиях;
* пока не тратьте много времени на сложные алгоритмы.
