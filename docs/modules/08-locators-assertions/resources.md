# Ресурсы: Модуль 08

## Официальная документация Playwright

- [Locators](https://playwright.dev/docs/locators) — способы выбора элементов, рекомендуемые встроенные локаторы, фильтрация и уточнение области поиска.
- [Assertions](https://playwright.dev/docs/test-assertions) — web-first assertions и основные проверки страницы и элементов.
- [Auto-waiting](https://playwright.dev/docs/actionability) — условия готовности элемента, которые Playwright проверяет перед действием.
- [Best Practices](https://playwright.dev/docs/best-practices) — официальные рекомендации по устойчивым тестам и локаторам, ориентированным на пользователя.
- [Debugging Tests](https://playwright.dev/docs/debug) — headed mode, Playwright Inspector и способы поиска причины ошибки.
- [Trace Viewer](https://playwright.dev/docs/trace-viewer) — просмотр trace с действиями, снимками страницы и диагностическими данными.
- [UI Mode](https://playwright.dev/docs/test-ui-mode) — интерактивный запуск и отладка тестов.

## Страница для практики

- [Playwright TodoMVC](https://demo.playwright.dev/todomvc/) — небольшое демонстрационное приложение для практики локаторов, действий и assertions.
