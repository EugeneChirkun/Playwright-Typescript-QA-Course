# Ресурсы: Модуль 11

## Практика

- [Репозиторий домашних заданий](https://github.com/EugeneChirkun/Pw-Ts-Qa-Hw) — отдельный репозиторий, в котором выполняются практические задания курса.

## Playwright

- [API testing в Playwright](https://playwright.dev/docs/api-testing) — официальное руководство по отправке запросов, подготовке состояния и проверке API.
- [APIRequestContext](https://playwright.dev/docs/api/class-apirequestcontext) — справочник по контексту запросов и методам `get()`, `post()`, `put()`, `patch()` и `delete()`.
- [APIResponse](https://playwright.dev/docs/api/class-apiresponse) — справочник по status code, headers, `ok()`, `json()` и другим данным response.

## HTTP и JSON

- [Обзор HTTP на MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) — введение в устройство обмена данными между клиентом и сервером.
- [Методы HTTP на MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Methods) — назначение методов `GET`, `POST`, `PUT`, `PATCH`, `DELETE` и других.
- [Status codes HTTP на MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status) — группы и значения кодов ответа сервера.
- [Headers HTTP на MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers) — справочник по headers request и response.
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) — публичный демонстрационный API для безопасных учебных запросов; операции изменения данных имитируются и не сохраняются постоянно.

## TypeScript

- [Everyday Types](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html) — официальное руководство TypeScript по базовым типам, объектам и type aliases для описания request и response data.
